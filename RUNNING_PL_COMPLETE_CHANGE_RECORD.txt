KEY IMPLEMENTATION DETAILS
================================================================================

ZERO-CROSSING INTERPOLATION:
───────────────────────────
Detects: When consecutive points cross y=0
Calculates: Exact time using linear interpolation
Formula: t = |balance_prev| / (|balance_prev| + |balance_next|)
Injects: Synthetic point at crossing moment
Result: Hard, precise boundary between green and red

EXAMPLE:
Point A: balance=50 at 09:14:00
Point B: balance=-30 at 09:15:00
Crossing: t = 50/(50+30) = 0.625 → 09:14:37.5
Creates: Synthetic point (0) at exact 09:14:37.5

NULL-MASKING ARCHITECTURE:
──────────────────────────
Old: Filtered data into separate arrays (breaks continuity)
New: Full dataset with masked values:
     - balancePositive = balance >= 0 ? balance : null
     - balanceNegative = balance <= 0 ? balance : null
Result: X-domain fully continuous, Recharts skips nulls

AREA CURVE INTEGRITY:
─────────────────────
Changed: type="monotone" → type="linear"
Reason: Linear curves cannot cross regime boundaries
Result: No smoothing artifacts, areas stay in domain

TOOLTIP AUTHORITY:
──────────────────
Uses: payload[0].payload.balance (full, unmasked)
Never: payload[0].value (could be null or zone-masked)
Result: Always shows true balance, never zone names

LEGEND CLEANLINESS:
───────────────────
Hidden: Both Area components (legendType="none")
Shows: Only "Running P&L" from Line component
Result: No implementation details leak to UI
