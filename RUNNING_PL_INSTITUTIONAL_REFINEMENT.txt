ISSUE #1: Zero-Crossing Interpolation (MANDATORY)
──────────────────────────────────────────────────

PROBLEM:
- Previous implementation used naive filtering
- When P&L crosses y=0, points were filtered into separate arrays
- Result: Visual artifacts, gaps, and vertical fill spikes at crossings
- Discontinuous X-domain at regime transitions

SOLUTION IMPLEMENTED:
1. Detect consecutive point crossings (different signs)
2. Calculate exact interpolation parameter: t = |prevBalance| / (|prevBalance| + |nextBalance|)
3. Interpolate exact timestamp where balance = 0
4. Inject synthetic point at: date = prevDate + t * (nextDate - prevDate)
5. This synthetic point exists in BOTH positive and negative series

MATHEMATICAL FORMULA:
  t = |prevBalance| / (|prevBalance| + |nextBalance|)
  crossingTime = prevDate.getTime() + t * (nextDate.getTime() - prevDate.getTime())
  
RESULT:
  ✅ No vertical spikes at zero crossings
  ✅ Color boundary is mathematically precise
  ✅ X-domain continuous (no gaps)
  ✅ Smooth visual transition from green to red

CODE LOCATION (Lines 130-164):

3. ZERO-CROSSING MECHANICS
================================================================================

HOW ZERO-CROSSING INTERPOLATION WORKS:
───────────────────────────────────────

SCENARIO:
Point A: balance = 50 (profit)
Point B: balance = -30 (loss)
Time between = 60 seconds

DETECTION:
- Different signs: 50 > 0 and -30 < 0 ✓ Crossing detected

INTERPOLATION:
- t = |50| / (|50| + |-30|) = 50 / 80 = 0.625
- This means crossing happens 62.5% of the way from A to B

TIME CALCULATION:
- If A is at 09:14:00 and B is at 09:15:00
- Time = 09:14:00 + 0.625 * 60 seconds = 09:14:37.5
- Synthetic point created at 09:14:37.5

RESULT IN DATA:
```
Original Points:   A(50)  →  B(-30)
With Interpolation: A(50) → Synthetic(0) → B(-30)
```

VISUAL RESULT:
- Green area ends exactly at 09:14:37.5
- Red area begins exactly at 09:14:37.5
- No gap, no overlap, no artifact
- Continuous X-domain

RECHARTS BEHAVIOR WITH NULL VALUES:
─────────────────────────────────────

Given data:
```
[
  { balance: -50, balancePositive: null,  balanceNegative: -50 },
  { balance: 0,   balancePositive: 0,     balanceNegative: 0 },
  { balance: 75,  balancePositive: 75,    balanceNegative: null },
]
```

Green Area (balancePositive):
- Renders null → 0 → 75
- Effect: Skips null, starts at 0, goes to 75
- Visual: Green fill only from 0 to 75

Red Area (balanceNegative):
- Renders -50 → 0 → null
- Effect: -50 to 0, then skips null
- Visual: Red fill only from -50 to 0

Line (balance):
- Renders -50 → 0 → 75 (no nulls)
- Effect: Continuous curve through all points
- Visual: Smooth line through all data
