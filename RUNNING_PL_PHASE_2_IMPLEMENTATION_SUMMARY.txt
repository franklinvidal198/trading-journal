FIX #1: ZERO-CROSSING INTERPOLATION
────────────────────────────────────

What It Does:
- Detects when consecutive data points cross the y=0 (breakeven) line
- Calculates exact time where balance would be exactly 0
- Inserts synthetic data point at that precise moment
- Ensures hard boundary between profit and loss regions

How It Works:
  Given: Point A (balance=50) at time 09:14:00
         Point B (balance=-30) at time 09:15:00
  
  Step 1: Detect crossing (50>0 and -30<0)
  Step 2: Calculate interpolation ratio
          t = |50| / (|50| + |-30|) = 50/80 = 0.625
  Step 3: Interpolate timestamp
          crossing_time = 09:14:00 + 0.625 * 60s = 09:14:37.5
  Step 4: Create synthetic point at 09:14:37.5 with balance=0
  Step 5: Insert into both positive and negative series

Code Location: Lines 130-164
```typescript

  const t = Math.abs(prevBalance) / (Math.abs(prevBalance) + Math.abs(nextBalance));
  const prevDate = new Date(...);
  const nextDate = new Date(...);
  const crossingTime = prevDate.getTime() + t * (nextDate.getTime() - prevDate.getTime());

}
```

FIX #2: NULL-MASKING ARCHITECTURE
──────────────────────────────────

What It Does:
- Replaces array filtering with null-value masking
- Keeps full dataset intact for all components
- Uses separate dataKeys for profit/loss rendering
- Preserves X-domain continuity

How It Works:
  OLD (Broken): Filter into positiveData[] and negativeData[]
                → Lost original data sequence
                → Discontinuous X-domain at crossings
  
  NEW (Correct): Keep enhancedData intact, add:
                 balancePositive = balance >= 0 ? balance : null
                 balanceNegative = balance <= 0 ? balance : null
                 → Recharts skips null values
                 → Data sequence preserved
                 → X-domain continuous

Example Data:
```
Before Crossing:
  balance: 50  → balancePositive: 50  | balanceNegative: null
  balance: 0   → balancePositive: 0   | balanceNegative: 0      (synthetic)
  balance: -30 → balancePositive: null | balanceNegative: -30
```

Green Area Rendering:
- Data: [50, 0, null, null]
- Effect: Renders 50 → 0, skips null
- Visual: Green fill from data to y=0

Red Area Rendering:
- Data: [null, 0, -30]
- Effect: Skips null, renders 0 → -30
- Visual: Red fill from y=0 to data

Code Location: Lines 94-128
```typescript
balancePositive: balance >= 0 ? balance : null,
balanceNegative: balance <= 0 ? balance : null,
```


FIX #3: LINEAR AREA CURVES

What It Does:
- Changes Area components from type="monotone" to type="linear"
- Prevents smooth curves from crossing regime boundaries
- Keeps Line component as type="monotone" for smooth appearance

Why It Matters:
