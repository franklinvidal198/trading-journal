COMMON QUESTIONS
================================================================================

Q: Why null-masking instead of filtering?
A: Filtering breaks X-domain continuity. Null-masking keeps all data
   points in sequence so X-axis remains continuous.

Q: Why linear not monotone for areas?
A: Monotone curves can smooth across the y=0 boundary, violating
   semantics. Linear segments cannot cross boundaries.

Q: What's synthetic point injection?
A: When data crosses y=0, we calculate exact crossing time using
   linear interpolation and inject a point at balance=0.

Q: How does null-masking work in Recharts?
A: When a dataKey value is null, Recharts doesn't render that point
   in the area. So balancePositive=null prevents that point in green
   area, and balanceNegative=null prevents it in red area.

Q: Why both areas show the same legend?
A: They don't. Both have legendType="none" so they're hidden. Only
   the Line component shows in legend as "Running P&L".

Q: How precise is the zero-crossing?
A: Uses linear interpolation formula: t = |prev| / (|prev| + |next|)
   Creates synthetic point at exact crossing time.
