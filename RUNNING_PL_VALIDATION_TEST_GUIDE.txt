COMMON ISSUES TO WATCH FOR
================================================================================

ISSUE: Red area visible above y=0
→ Check: null-masking logic (balanceNegative should be null)
→ Likely cause: dataKey mapping incorrect

ISSUE: Gaps at zero crossings
→ Check: Synthetic point injection logic
→ Verify: Data contains interpolated point at crossing

ISSUE: Tooltip shows null or "Profit Zone"
→ Check: CustomTooltip using payload[0].payload.balance
→ Verify: Not using payload[0].value

ISSUE: Smooth curve crosses regime boundary
→ Check: Area type="linear" not "monotone"
→ Verify: Line is type="monotone" (only this should smooth)

ISSUE: "Profit Zone" / "Loss Zone" in legend
→ Check: legendType="none" on both Area components
→ Verify: Legend only shows "Running P&L"
