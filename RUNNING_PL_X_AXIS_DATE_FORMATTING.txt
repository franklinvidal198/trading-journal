CHANGE #2: Date Formatting Function
────────────────────────────────────

New helper function inside useMemo:

const formatDisplayDate = (dateInput: string | Date | null) => {
  // Parse ISO date string
  const date = new Date(dateStr);
  
  // Extract parts
  const month = date.toLocaleString('en-US', { month: 'short' });
  const day = date.getDate();
  const hours = String(date.getHours()).padStart(2, '0');
  const minutes = String(date.getMinutes()).padStart(2, '0');
  
  return {
    short: `${month} ${day} ${hours}:${minutes}`,    // "Jan 4 09:14"
    full: `${month} ${day}, ${date.getFullYear()} ${hours}:${minutes}`
  };
};

Purpose:
- Converts ISO dates to human-readable format
- Handles different date input types (string, Date object, etc.)
- Generates both compact and full versions
- Uses locale-aware month names (Jan, Feb, Mar, etc.)

const CustomTooltip = ({ active, payload }: any) => {
  if (active && payload && payload.length) {
    const data = payload[0].payload;
    const balance = data.balance;

    return (
      <div className="bg-slate-950 border border-slate-700 rounded-lg p-3 shadow-lg">
        <p className="text-sm text-slate-300">
          {data.displayDateFull || data.displayDate || data.date}
        </p>
        <p className={`text-lg font-bold ${balance >= 0 ? "text-green-400" : "text-red-400"}`}>
          {formatCurrency(balance)}
        </p>
        <p className="text-xs text-slate-400">
          {balance >= 0 ? "+" : ""}{balance.toFixed(2)} Running P&L
        </p>
      </div>
    );
  }
  return null;
};

Result: Tooltip shows full date context to user


CHANGE #5: X-Axis Smart Formatting
───────────────────────────────────

Updated XAxis configuration:

<XAxis
  dataKey="displayDate"
  stroke="#64748b"
  tick={{ fontSize: 11 }}
  interval={Math.max(0, Math.floor(enhancedData.length / 8) - 1)}
  angle={-45}
  textAnchor="end"
  height={80}
/>

What This Does:
- dataKey="displayDate": Uses compact date+time format
- tick={{ fontSize: 11 }}: Slightly smaller font for readability
- interval: Smart tick spacing (shows ~8 ticks max to avoid crowding)
  Formula: Math.floor(dataLength / 8) - 1
  Example: 100 points → show every ~12th point
- angle={-45}: Rotates labels 45 degrees for readability
- textAnchor="end": Aligns text properly with rotation
- height={80}: Extra bottom margin for rotated labels

Result: Clean, readable X-axis that never crowds

SMART TICK SPACING EXPLAINED
================================================================================

How Automatic Tick Spacing Works:

interval={Math.max(0, Math.floor(enhancedData.length / 8) - 1)}

Examples:
- 16 data points: interval = floor(16/8) - 1 = 1 (show every 2nd point)
- 80 data points: interval = floor(80/8) - 1 = 9 (show every 10th point)
- 100 data points: interval = floor(100/8) - 1 = 11 (show every 12th point)
- 160 data points: interval = floor(160/8) - 1 = 19 (show every 20th point)

Result: ~8 labels regardless of data size (perfect for readability)
